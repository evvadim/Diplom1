# Дипломный проект. Часть 2. Задание 1. Юнит-тесты
Проект по тестированию программы заказа бургера

## Технологии
- IntelliJ IDEA 2025.2.4
- JDK Corretto 11.0.28
- Build System Maven 3.9.11
- JUnit 4.13.2
- Mockito 5.18.0
- Jacoco 0.8.12

1. Протестирован метод подсчета стоимости `.getPrice()` параметрическим тестом
2. Протестирован метод получения рецепта бургера `.getReceipt()` парметрическим тестом
3. Протестированы методы добавления/изменения ингредиентов бургера:
    * `.setBuns()`
    * `.addIngredient()`
    * `.removeIngredient()`
    * `.moveIngredient()`

## Запуск тестов
```
mvn clean test
```

## Генерация отчета Jacoco
```
mvn verify
```
